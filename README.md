# College Event Portal

A responsive dark-themed college event management website for browsing campus events, registering for activities, and managing event data in-browser.

## Features

- Event listing with search and category filters
- Student registration workflow
- My registrations section for viewing saved bookings
- Admin dashboard for managing event records
- Local browser storage using `localStorage`
- Mobile-friendly responsive layout
- Dark mode visual theme with modern card-based design

## Project Structure

- `index.html` — page structure and layout
- `styles.css` — styling and responsive design
- `script.js` — event logic, rendering, and local storage behavior

## How to Run

1. Open the project folder in your browser.
2. Double-click `index.html` to open it, or run a local server.

```bash
cd "c:\Users\HP\OneDrive\Desktop\kaam dhaam\college-event-portal\college-event-portal"
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

- This project is frontend-only.
- Data is saved in the browser, so it is not shared across devices.
- It is designed as a demo/event portal for a college project.
